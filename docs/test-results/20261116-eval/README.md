# VISTA 视觉记忆对照实验结果

执行日期为 2026-11-16。最终有效样本为 12 个基础案例、两组各两次重复，共 48 次真实模型运行。

文字历史组成功 18/24，允许回读历史原图组成功 24/24，成功率分别为 75% 和 100%，配对差值为 25 个百分点。以基础案例重采样的 95% bootstrap 区间为 0 至 50 个百分点。[完整统计](v2/formal/paired-summary.json)、[逐案例结果](v2/formal/paired-summary.csv)

收益集中于三个基础案例，两个重复中均出现相同的成败差异。

- R1-03 的正确选择为 control=4。文字组选择了 control=3，两条记录的粗粒度摘要均描述为稀疏条纹。原图组正确区分了条纹间距。
- R2-03 的最大条纹间距变化发生在 control=1→2。文字组选择了 2→3，原图组选择正确。
- R2-04 的最大亮度变化发生在 control=3→4。文字组选择了 2→3，原图组选择正确，两组对后续变暗方向的预测一致。

文字组在这些回答中注明了摘要不足以支持精确区分或数值变化判断。三个详细摘要案例中，两组均全部成功。观察结果支持原图回读在摘要丢失具体视觉差异时的价值。

R3 的 16 个有效动作均重新执行了绘图程序，实际图像与对应目标的平均通道像素误差为 0。该组任务中两条件均完成了正确行动选择。

## 实验设置与证据

模型为 `gpt-6.1-sol`，宿主为 DeepSeek Harness `0.2.2-rc.2` SDK runtime，推理设置为 `high`，每请求输出上限 8192 tokens。每次运行采用独立进程、home 和会话，正式两组共享固定空工作目录，宿主工具集合仅有两项 VISTA 读取工具。

两条件获得相同任务提示、目标图、当前图、历史摘要、记录引用和实际外部参数。条件适配器复用原 MCP 服务，文字组将历史图片块替换为固定可用性说明，原图组收到实际 PNG。单次预算为两次列目录、八次读取和 300 秒。

逐运行核验覆盖了以下内容。

- 共同图片从源文件、DSH 用户附件到实际 HTTP 图片的对应关系，以及 A/B 转换后图片哈希一致。
- 文字组工具结果与实际 HTTP 工具输出中均无历史图片。
- 原图组已经读取的历史图片，从源 PNG、工具附件到 HTTP 图片的哈希一致。
- 共同图片与历史图片的哈希分离，防止附件哈希直接提供匹配答案。
- 实际模型、推理配置、工具数量、调用预算与任务时间。
- 决策字段、所引用历史记录，以及实际执行动作后的目标误差。

全部实验阶段共发起 122 次模型 HTTP 请求，均返回 200。最终 48 次有效运行均通过输入与传输校验，六次任务失败均来自文字组的答案选择。[协议](protocol.md)、[原始冻结记录](freeze-v2.json)、[编码修复冻结记录](freeze-v3.json)

## 校准与补跑

实际执行了 60 次 Agent 运行。

| 阶段 | 运行数 | 处理 |
| --- | --- | --- |
| 首轮校准 | 4 | 发现附件哈希匹配捷径，保留原始记录 |
| 修正后校准 | 4 | 两组共同输入与历史哈希分离，全部通过 |
| 首轮正式运行 | 48 | 正常结束，其中 R2-03 的四次输入质量检查失败 |
| R2-03 编码修复补跑 | 4 | 完整替换该案例的两组、两次重复 |

首轮校准的 CAL-02 原图组明确引用目标图与历史图的相同 SHA-256 作答。v2 给共同图片添加中性 PNG 编码标记，保持解码像素一致，消除了这一捷径。[首轮校准](calibration/paired-summary.json)、[修正后校准](v2/calibration/paired-summary.json)

DSH 会将带 metadata 的共同输入转换为 JPEG。R2-03 的当前图平均通道误差为 5.0633/255，超过预先固定的 5/255 容差，因此四次正式尝试判为输入质量失败。v3 对该案例采用纯 PNG 的独立压缩编码，像素完全相同，附件与出站阶段均无损透传。题目、历史记录、真值、模型和评分阈值沿用原设置。[修复记录](encoding-repair.md)、[修复前评分快照](v2/formal/analysis-v2/paired-summary.json)

52 次正式尝试的全量统计为 42 次任务成功、6 次答案失败、4 次输入质量失败，全量通过率为 80.8%。最终配对统计选取预定的 48 次有效运行，补跑依据为输入质量失败。

## 结论范围

本轮使用四种确定性绘图机制，GLSL 为 `null`。这些合成任务验证了历史视觉比较、局部单因素变化判断和有限动作选择。真实 Shader 渲染任务及更广泛多模态任务的收益仍待后续评估。

12 个案例共享四种生成机制，属于小规模探索。总体置信区间包含 0。摘要详细程度与场景类型相关，`compacted_context` 标签采用重建上下文来模拟保留摘要，因此摘要分组或场景标签之间的差异仅作描述。

## 复核与工具修订

最终数据清单为 [dataset-v3/manifest.json](dataset-v3/manifest.json)。各案例的私有真值、图片及提示随数据归档，逐运行目录保留原始轨迹、HTTP 摘要、转换后的共同图、动作图和评分。

```bash
.venv/bin/python scripts/score_vista_memory_eval.py \
  --dataset docs/test-results/20261116-eval/dataset-v3/manifest.json \
  --output docs/test-results/20261116-eval/v2 \
  --phase formal
```

全部模型运行结束后，修复了评分器在任务超时情况下可能遗漏配对的分支，并为运行器补充超时阶段及指定重复编号。六种无模型故障回归通过，本轮完整统计在修复前后逐字段相同。执行时的冻结脚本已归档。[修订记录](analysis-revision.json)、[故障回归](scorer-failure-regression.json)、[冻结脚本索引](frozen-execution-scripts/index.json)

工作区的评分器可直接复核移动后的归档。复制时保留 `dataset-v2`、`dataset-v3` 和 `v2/formal` 的同级关系，v3 的多数输入与 v2 共用。以下命令按原始清单校验两次实验的全部冻结文件，优先使用索引中保存的历史版本。

```bash
.venv/bin/python scripts/verify_vista_freeze.py \
  docs/test-results/20261116-eval/freeze-v2.json \
  docs/test-results/20261116-eval/freeze-v3.json
```
