# VISTA 视觉记忆对照实验协议

编制日期为 2026-11-16。正式运行前固定本协议、数据、提示、评分规则和代码哈希。

## 研究问题与适用范围

在相同视觉模型、目标图、当前图、历史文字摘要和实际参数下，增加历史原图的按需回读，是否改善历史图像比较、受控单因素变化分析和下一步行动选择。

首轮采用确定性绘图程序，覆盖四种场景机制。GLSL 字段为 `null`，实际外部输入记录在 `render` 中。程序内部实现由评估方固定并记录版本。结论适用于这组任务及采用的文字摘要方法。

R1 的历史视觉匹配、R2 的局部变化分析和 R3 的行动选择分别报告。每类包含一项信息较完整的文字摘要案例，其余采用统一生成的粗粒度摘要。caption 函数依据图像特征生成摘要，题目和答案由后续任务构造决定。

## 实验条件

| 条件 | 共同材料 | 历史工具返回 |
| --- | --- | --- |
| text | 相同提示、目标图、当前图、历史摘要、记录引用、实际外部参数 | 保留原元数据与文字，图片块替换为固定可用性说明 |
| visual | 与 text 一致 | 原元数据、文字和 PNG 图像块 |

两组使用同一 MCP 服务注册逻辑和工具 schema。每次运行创建独立 DSH SDK 进程、home 与会话，正式运行共享一个固定空工作目录，使宿主注入的工作目录文字一致。两组的历史数据根目录相同且仅用于读取。目标图、当前图和真值保存在历史图片记录目录之外。

模型输入首先包含目标图，其后为当前图。共同图片的像素可以与历史图片相同。v2 对目标图和当前图加入中性 PNG 文本编码标记，保持像素完全一致，并使附件哈希与历史图片不同。检查图片来源时同时核对 HTTP 中的用户图片与工具结果图片位置，以及实际出站哈希的差异。

## 案例与运行

- 校准使用 2 个额外案例，每个案例执行 text、visual 各一次，共 4 次运行。
- 正式使用 12 个基础案例，R1、R2、R3 各 4 个。每个案例执行两条件、各两次重复，共 48 次运行。
- 每例有 6 条历史记录。单次预算为最多 2 次目录调用、8 次读取、300 秒任务时间。
- 固定 `gpt-6.1-sol`、DSH `0.2.2-rc.2`、`reasoningEffort=high`、每请求输出上限 8192 tokens。
- 按种子 `20261116` 随机安排案例与条件顺序。每对 text/visual 顺序执行，最多两个案例对并行。

部分案例标为 `compacted_context`，任务阶段通过统一重建上下文模拟压缩后可见材料。另一些标为 `new_session`。两者均由新 SDK 会话执行，标签描述构造情境，真实宿主自动压缩行为留待专门评估。

## 真值和评分

R1 预先确定唯一正确历史记录及必要证据引用。R2 每一步以相同步长改变一个控制量，测量唯一最大视觉变化的相邻对，预测相同局部区间内继续增大控制量的方向。R3 穷举给定动作，实际生成图像并计算与目标的误差，确定唯一最佳动作。

主指标要求相关决策字段和必要历史证据引用都正确。模型输出使用固定 JSON schema，无法解析的答案计为任务失败。自由文字解释保存为辅助观察，客观真值与确定性评分承担主判定。

R3 对每个模型选择的动作再次执行生成程序，保存动作图和实测误差。预算耗尽、超时和普通错误答案计入完整运行失败。明确基础设施故障保存原始轨迹，并通过新的 attempt 编号整对补跑。

统计先汇总每个基础案例的重复表现，再计算两条件的配对差值。报告任务类型与摘要粒度的分项结果。bootstrap 以基础案例为单位，种子固定为 `20261116`，采用 10,000 次重采样。12 个案例共享四种生成机制，区间与差值作为本轮探索性结果。

## 校准与冻结

校准检查输入图片、工具调用、题目可解性、唯一真值、答案格式和评分脚本。将校准修正记录在实验记录中。正式运行后修改输入、模型配置或任务规则时，建立新实验版本并完整重跑相关配对。

首轮 4 次校准发现 CAL-02 的 visual 回答直接引用目标图与历史图相同的 SHA-256。该批保留为方法问题发现记录。v2 采用上述编码修正并增加 4 次校准，正式实验仍为 48 次。两轮校准使用独立输出目录和对应数据清单。

v2 校准中，DSH 将共同输入转换为 JPEG。评分检查源 PNG、用户消息中的附件和实际 HTTP 用户图之间的对应关系，归档转换后的图片，核对尺寸相同且平均通道像素误差不超过 5/255。校准实测误差为 1.015679 至 1.509223/255。两组的转换后图片哈希相同，且与历史图片哈希分开。

正式运行的工作目录固定化在校准后完成，用于消除宿主提示中的运行名称差异。任务提示、数据、模型配置和评分规则沿用 v2 校准版本。

冻结文件保存协议、数据清单、逐案例提示和真值、PNG、生成器、条件适配器、运行器、审计插件与评分脚本的 SHA-256。正式执行入口逐次核对这些哈希。

## 证据要求

- 两条件每对提示与共同图片哈希相同。
- 实际模型工具集合为两项 VISTA 读取工具。
- text 的工具结果和实际 HTTP 工具输出中均无历史图片。
- visual 已读取的历史图片从源 PNG、工具附件到 HTTP 图片哈希一致。
- 在整次运行轨迹中统计工具调用与预算，保留失败请求。
- 记录模型实际推理配置、用量、耗时和执行顺序。

HTTP 审计保留派生哈希、图片来源、请求模型与响应状态。凭据由现有 DSH 配置在运行时解析。
