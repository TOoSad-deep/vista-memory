# VISTA 图片回看目录 v1.1 实施报告

图片登记、来源备注、短目录和按短号回读已接通。原生 DSH 检查了保存回执、历史裁剪后的目录投递，以及回读原 PNG 实际进入模型请求的过程。[宿主验收与接入方式](host.md)

## 实施与核验

| 阶段 | 交付和验收 |
| --- | --- |
| 0 · 最小提醒 | 一行固定线索、真实请求核对、隐含反馈的查询与主动提醒对照。[固定线索证据](host.md) |
| 1 · 保存登记 | 任务短号、稳定请求 ID、SQLite 登记和文件发布清单。子进程强制终止后重试，核对预留、PNG、新 GLSL、JSON 发布后四个中断点，以及已有 GLSL、重复和并发写入。[登记测试](../../../tests/test_history_store.py) |
| 2 · 备注 | 明确短号及单图回复可写，含糊反馈保留在聊天，用户与 Agent 事件分开去重。原生 DSH 接入后另查实际写入和补写的模型往返。[备注测试](../../../tests/test_history_catalog.py) · [宿主证据](host.md) |
| 3 · 目录 | 短目录、组与其余图片的文字分页、按短号读原图。切换选中图时，旧游标继续遍历原视图。目录保留原话，并在回读发现图片缺失时标记。[目录测试](../../../tests/test_history_catalog.py) |
| 4 · 原生 DSH | 受控裁剪的追加次数为 0、1、0。另测同时退出、再次退出和分组入口仍在。实际宿主的 `/compact` 与原生图片卸载重试分别留存请求证据。[宿主验收](host.md) |
| 5 · 配对实验 | 两套图标，分别比较提醒与按需查询，以及 A、B1、B2 的目录导航和备注。[逐例结果](paired.md) |

阶段 1 的恢复会保留归属不明的文件。如果进程恰在独占创建临时文件之后、SQLite 记录文件身份之前终止，重试会报告归属冲突，文件留供检查。目录视图保存在任务数据库中，当前实现没有定期淘汰。
